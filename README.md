# 🔐 IPFS Encryption Suite

A multi-page web application for storing encrypted data on IPFS using symmetric (AES) or asymmetric (RSA) encryption.

## Features

- **Symmetric Encryption (AES-256)**: Single secret key for encryption and decryption
- **Asymmetric Encryption (RSA-2048)**: Public/private key pair
- **File Support**: Upload and encrypt files (base64 encoded)
- **IPFS Storage**: Decentralized storage with content-addressed CIDs
- **Multi-page Architecture**: Clean separation of concerns
