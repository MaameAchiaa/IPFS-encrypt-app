Encrypt and decrypt using a single secret key

Use a strong key. The same key is needed for decryption.
💡 Export data to share with others (works even without IPFS)
✅ Ready

💡 How it works

  1. Enter your secret key or use the default
  2. Type text or upload a file
  3. Click "Encrypt & Store" → Data is encrypted and stored locally
  4. The ID appears automatically in the field below
  5. To share: Click "Export Encrypted Data" and send the file
  6. To receive: Click "Import Encrypted Data" and select the file
  7. Click "Decrypt" to retrieve your data

📦 Data is stored locally in your browser. Export/Import to share!
