💡 How to Share When IPFS is Unavailable

👩 Sender
  1. Encrypts message
  2. Clicks "Export Encrypted Data"
  3. Downloads the .json file
  4. Sends the file to recipient
👨 Recipient
  1. Receives the .json file
  2. Clicks "Import Encrypted Data"
  3. Selects the file
  4. Pastes their private key
  5. Clicks "Decrypt"
  6. ✅ Reads the message!

🔒 Security: The recipient must provide their private key to decrypt — proving they are the intended recipient.

⚡ Hybrid mode: AES-256 + RSA-2048 (No size limit, fast, and secure).
